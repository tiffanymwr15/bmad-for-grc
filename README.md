# BMAD for GRC Engineering

A course Tiffany made for GRC Engineering Club members on applying the [BMAD method](https://github.com/bmad-code-org/BMAD-METHOD) when agents write controls, evidence, and catalog entries.

**Time:** about 90 minutes, or one lesson per meeting. Leave time at the end to try the playbook on a real change.

**You need:** a browser. The visual course loads two fonts from Google Fonts, so the page looks right with a network connection. The words still read if those fonts do not load.

## Start here

Open the course: [https://tiffanymwr15.github.io/bmad-for-grc/](https://tiffanymwr15.github.io/bmad-for-grc/)

Or open [course.html](course.html) from this folder. Use the lesson list on the left. Each lesson ends with a button to the next one. The last lesson ends with the learning resources.

Answer the self-check questions before you open [answer-key.md](answer-key.md).

The worked example is a privileged-access review on a fixed interval. No stack is named. Replay the same shape on a control you actually operate.

## How a club session can run

1. Open `course.html` and start at **What BMAD is**. Read the definition and the two-path diagram before lesson 1.
2. Move through the lessons with the continue buttons. The diagrams are the spine. The self-checks are the work.
3. On lesson 4, try the stop-routing questions out loud before you reveal the result. Then walk the checklist against a change someone in the room is about to make.
4. Compare answers with `answer-key.md` after the attempt, not before.

A facilitator can share one screen for the diagrams and let people answer the checks on their own before the key goes up.

## Lessons

| # | Lesson | You should be able to |

| 3 | [Apply it](03-apply-it.md) | Walk one new control from obligation to evidence and a catalog entry |
| 4 | [The human loop](04-the-human-loop.md) | Classify a loop stop by owner, and run the playbook on the next change |

## Learning resources

- [BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD), the open-source framework
- [BMad workflow map](https://bmad-code-org-bmad-method-6.mintlify.app/reference/workflow-map), each phase and the document it produces
- [Port's explainer of the BMad Loop](https://www.port.io/blog/bmad-method-explained), the source for routing a stop to the person who owns it

This course is a club translation of that method for GRC engineering. It is not a Port product, and it is not tied to one pipeline.
